# MetroFlow Raw Data

本目录当前只保留真实原始观测数据。

保留文件：

- `inout_10min_3km.parquet`：10 分钟进出站观测
- `od_internal_10min_3km.parquet`：10 分钟 OD 观测
- `MetaData_workday_calendar.csv`：工作日历
- `MetaData_shanghai_weatherHourly.csv`：逐小时天气
- `stations_3km.geojson`：站点空间范围
- `manifest_metroflow.json`：数据说明

旧的八时段校准说明和相关派生文件已经移到 `_deprecated/`。
