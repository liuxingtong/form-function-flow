# 城市设计平台 AI 功能分配规则文档

## 引导式对话流程与无代码量化功能排布规则

---

## 1. 文档目标

本文件用于说明城市设计平台中“AI 辅助功能分配”的产品逻辑与规则框架。

平台中已经加载 Rhino 建筑体量模型，并已划分四个分区：

1. 中央商务区；
2. 休闲商业区；
3. 住宅区；
4. 文化创意产业园。

用户在前端对话框中输入城市设计愿景后，AI 需要根据用户愿景、服务人群、分区角色、建筑体量条件和楼层段特征，为不同建筑体块及其楼层段推荐合适功能。

本功能定位为城市设计前期的辅助判断工具，而不是最终业态策划工具，也不是规划审批级别的强规则系统。

其目标是：

- 快速形成初步功能结构；
- 避免功能命名混乱和语义重复；
- 让功能落位有基本规划逻辑；
- 支持用户通过自然语言继续调整；
- 输出可解释、可修改的功能排布建议。

---

## 2. 总体逻辑

主流程为：

**愿景输入 → 参数转译 → 分区定位 → 功能本体 → 空间属性 → 楼层段 → 评分 → 分配 → 校验 → 输出**

更适合开发理解的执行逻辑为：

| 阶段 | 作用 |
|---|---|
| 愿景输入 | 获取用户对城市气质和发展方向的描述 |
| 参数转译 | 将自然语言转化为若干规划倾向参数 |
| 分区定位 | 明确 CBD、休闲商业区、住宅区、文创园各自角色 |
| 功能本体 | 只从标准功能库选择功能，避免语义重复 |
| 空间属性 | 根据体块条件判断适合功能 |
| 楼层段 | 判断首层、裙房、中层、高层、屋顶适合什么 |
| 评分 | 对候选功能进行量化适配判断 |
| 分配 | 给体块或楼层段确定主功能和次功能 |
| 校验 | 检查冲突、语义重复和比例失衡 |
| 输出 | 输出功能标签、推荐理由、冲突提醒和调整方向 |

执行优先级为：

**分区约束优先 → 硬冲突排除 → 楼层段适配 → 空间条件细化 → 用户愿景加权 → 分区比例校正 → 输出结果**

核心原则：

> 用户愿景用于调整权重，但不能推翻基本规划逻辑。  
> 分区决定能放什么，愿景决定更偏向什么，楼层段决定放在哪里，空间属性决定哪栋更合适，冲突规则决定哪些不能放，比例校正决定整体是否均衡。

---

# 3. 前端引导式对话流程

前端对话应采用 **轻量引导 + 可跳过 + 可自定义输入** 的方式。

除第一个“愿景描述”环节外，后续所有环节都应允许用户选择：

1. 系统预设选项；
2. 待定；
3. 其它：用户自行输入。

AI 不应要求用户必须完整填写所有信息。  
如果用户选择“待定”或没有提供某些信息，AI 应根据已经输入的愿景、分区关系和默认规则自动推断缺失字段，并在输出中说明哪些信息是用户明确提供的，哪些是 AI 推断补全的。

---

## 3.1 第一步：一句话描述愿景

这是唯一建议用户必须填写的环节。

### 引导问题

> 你希望这个片区最终呈现出什么样的城市气质？请用一句话描述。

### 示例回答

> 希望它成为一个兼具商务效率、滨水休闲、青年创意和高品质居住的复合型城市中心。

### 作用

这一句话是后续推断的基础。AI 应从中提取整体倾向，例如：

- 商务强度；
- 休闲消费强度；
- 居住安静度；
- 文创强度；
- 夜间活力；
- 公共开放度；
- 混合使用度；
- 地标需求。

---

## 3.2 第二步：服务人群画像

### 引导问题

> 这个片区主要服务哪些人群？可以选择，也可以填写其它，暂时不确定可以选择待定。

### 可选项

| 选项 | 功能倾向 |
|---|---|
| 商务办公人群 | 增加办公、酒店、会展、商务餐饮 |
| 年轻消费人群 | 增加特色餐饮、娱乐、潮流零售、夜间消费 |
| 创意产业人群 | 增加创意办公、设计工作室、展览、发布空间 |
| 家庭居住人群 | 增加住宅、社区服务、教育、生活商业 |
| 游客与外来访客 | 增加酒店、文化展示、商业街区、公共活动 |
| 待定 | AI 根据愿景自动推断 |
| 其它 | 用户自行输入，AI 归并到最接近的人群画像 |

### 待定时的推断规则

| 愿景关键词 | 推断人群 |
|---|---|
| 商务、总部、金融、国际化、高效 | 商务办公人群 |
| 年轻、潮流、夜生活、消费、活力 | 年轻消费人群 |
| 艺术、设计、创新、创意、文化 | 创意产业人群 |
| 宜居、社区、家庭、安静、生活 | 家庭居住人群 |
| 旅游、地标、打卡、文化消费 | 游客与外来访客 |

### 其它输入的归并示例

| 用户输入 | 系统理解 |
|---|---|
| 高净值商务旅客 | 商务办公人群 + 游客与外来访客 |
| 周边高校学生 | 年轻消费人群 + 创意产业人群 |
| 本地居民和通勤白领 | 家庭居住人群 + 商务办公人群 |
| 艺术家、设计师、独立品牌主理人 | 创意产业人群 + 年轻消费人群 |

---

## 3.3 第三步：四个分区的优先级

### 引导问题

> 在这四个分区中，你希望哪个分区成为整体设计的核心？可以选择待定或自行描述。

### 可选项

1. 中央商务区作为核心；
2. 休闲商业区作为核心；
3. 文化创意产业园作为核心；
4. 住宅区作为稳定生活核心；
5. 四个区均衡发展；
6. 待定；
7. 其它：用户自行输入。

### 待定时的推断规则

| 愿景倾向 | 推断核心分区 |
|---|---|
| 商务、总部、金融、办公、门户形象 | 中央商务区 |
| 消费、夜间活力、游逛、街区、滨水休闲 | 休闲商业区 |
| 创意、艺术、设计、文化生产、展览 | 文化创意产业园 |
| 宜居、安静、社区、生活品质 | 住宅区 |
| 复合、均衡、产城融合、全天候 | 四区均衡发展 |

### 其它输入的归并示例

| 用户输入 | 系统理解 |
|---|---|
| 希望以滨水商业带带动整体 | 休闲商业区为核心，文创园和 CBD 辅助 |
| 希望办公和文创共同驱动 | CBD 与文创园共同作为核心 |
| 希望住宅稳定，但不要太封闭 | 住宅区为生活核心，同时提高公共界面开放度 |
| 希望先做一个可招商的启动区 | 优先强化交通可达性最高或公共界面最强的分区 |

---

## 3.4 第四步：活力时段

### 引导问题

> 你希望这个片区主要在什么时间段保持活力？可以选择待定或自行描述。

### 可选项

| 选项 | 功能倾向 |
|---|---|
| 白天活力 | 办公、会展、教育、展览、社区服务 |
| 夜间和周末活力 | 餐饮、剧场、娱乐、休闲商业、酒店 |
| 全天候活力 | 办公、居住、商业、文化混合布置 |
| 待定 | AI 根据愿景自动推断 |
| 其它 | 用户自行输入 |

### 待定时的推断规则

| 愿景关键词 | 推断活力时段 |
|---|---|
| 办公、高效、产业、商务 | 白天活力 |
| 夜生活、餐饮、演艺、消费、年轻 | 夜间和周末活力 |
| 复合、混合、产城融合、城市中心 | 全天候活力 |
| 宜居、社区、家庭、生活 | 早晚与周末的社区型活力 |

### 注意事项

夜间活力不能直接导向住宅区内部娱乐化。  
如果住宅区需要保持安静，夜间活力应主要落在休闲商业区、文创园开放界面和 CBD 公共界面。

---

## 3.5 第五步：开放程度

### 引导问题

> 你希望整体空间更偏安静宜居，还是更偏开放热闹？可以选择待定或自行描述。

### 可选项

| 选项 | 功能倾向 |
|---|---|
| 安静宜居 | 住宅、社区服务、文化教育、低噪声商业 |
| 开放热闹 | 餐饮、零售、展演、娱乐、会展 |
| 层次混合 | 主街开放，内院安静；外围商业，内部居住 |
| 待定 | AI 根据愿景自动推断 |
| 其它 | 用户自行输入 |

### 待定时的推断规则

| 愿景关键词 | 推断开放程度 |
|---|---|
| 宜居、安静、高端住宅、社区 | 安静宜居 |
| 活力、开放、消费、游客、街区 | 开放热闹 |
| 复合、过渡、平衡、生活与商业结合 | 层次混合 |
| 滨水、慢行、公共空间 | 开放热闹或层次混合，视住宅要求判断 |

### 默认建议

如果用户未明确选择，优先采用“层次混合”。

也就是：

> 主街和公共空间开放，住宅内院和生活空间保持安静。

---

## 3.6 第六步：地标或公共核心

### 引导问题

> 是否希望形成一个明显的城市地标或公共活动核心？可以选择待定或自行描述。

### 可选项

1. 需要明显地标；
2. 需要公共活动核心，但不一定是高层地标；
3. 不强调地标，更强调街区整体氛围；
4. 待定；
5. 其它：用户自行输入。

### 待定时的推断规则

| 愿景关键词 | 推断结果 |
|---|---|
| 地标、门户、形象、国际化、城市客厅 | 需要明显地标 |
| 广场、公共活动、展演、社交、滨水节点 | 需要公共活动核心 |
| 街区、慢行、生活、社区、尺度友好 | 不强调高层地标，更强调整体氛围 |
| 复合中心、城市核心 | 可设置一个公共核心和若干次级节点 |

### 分区对应关系

- CBD 适合形成高层或总部型地标；
- 休闲商业区适合形成公共广场、消费核心或夜间活动核心；
- 文创园适合形成文化展览、发布活动或艺术地标；
- 住宅区不宜作为强地标核心，但可设置社区中心或生活节点。

---

# 4. 缺失字段自动补全规则

如果用户没有完整回答所有引导问题，AI 应自动补全缺失字段。

补全逻辑应遵循以下优先级：

**用户明确输入 > 用户自定义输入 > 愿景语义推断 > 分区默认规则 > 系统默认值**

---

## 4.1 信息来源优先级

| 优先级 | 信息来源 | 说明 |
|---|---|---|
| 1 | 用户明确选择 | 最高优先级 |
| 2 | 用户自定义输入 | AI 需理解并归并到参数 |
| 3 | 愿景语义推断 | 从一句话愿景中提取倾向 |
| 4 | 分区默认规则 | 使用 CBD、休闲商业、住宅、文创园的默认定位 |
| 5 | 系统默认值 | 无明显倾向时采用中性或均衡方案 |

---

## 4.2 待定字段处理方式

当用户选择“待定”时，不应中断流程，不应强迫用户补充。

AI 应执行：

1. 保留该字段为“未明确指定”；
2. 根据愿景关键词推断一个默认判断；
3. 在最终结果中标记为“AI 推断”；
4. 允许用户后续修改。

### 示例

| 字段 | 用户选择 | AI 推断 |
|---|---|---|
| 服务人群 | 待定 | 根据“青年创意、夜间活力”推断为年轻消费人群 + 创意产业人群 |
| 核心分区 | 待定 | 根据“商务效率”推断 CBD 为重要核心 |
| 活力时段 | 待定 | 根据“夜间活力”推断为夜间和周末活力 |
| 开放程度 | 待定 | 根据“复合型城市中心”推断为层次混合 |
| 地标需求 | 待定 | 根据“城市中心”推断需要公共活动核心 |

---

## 4.3 其它输入处理方式

当用户选择“其它”并自行输入时，AI 应尽量归并到已有标准参数中，而不是新增大量不可控字段。

处理方式：

1. 识别用户输入的核心含义；
2. 映射到已有参数；
3. 如果无法完全映射，则作为补充说明保留；
4. 不因此新增模糊功能名称。

### 示例

| 用户自定义输入 | 参数映射 |
|---|---|
| 希望吸引高校学生和独立设计师 | 年轻消费强度提高，文创强度提高，人才公寓和设计工作室权重提高 |
| 希望服务金融白领和商务旅客 | 商务强度提高，商务酒店、商务餐饮、总部办公权重提高 |
| 希望周边居民晚上也愿意来散步消费 | 休闲消费强度提高，夜间活力小幅提高，公共开放度提高，但住宅区保持低噪声 |
| 希望有艺术节和发布会 | 文创强度提高，文化展览、剧场演艺、商务会展权重提高 |
| 希望不要变成普通商业街 | 休闲消费强度不过度提高，文创强度提高，文化展览和设计工作室优先 |

---

# 5. 用户输入的量化参数

用户不需要直接填写数字，但系统应将对话内容转译为若干 0—100 的倾向参数。

默认值可设为 50。  
用户明显强调某项时，该项可提升至 70—90。  
用户明显排斥某项时，该项可降低至 10—30。

---

## 5.1 核心参数

| 参数 | 含义 | 高值意味着 |
|---|---|---|
| 商务强度 | 是否偏商务办公和总部经济 | 更多办公、酒店、会展、商务餐饮 |
| 休闲消费强度 | 是否强调消费、游逛和体验 | 更多零售、餐饮、娱乐、精品酒店 |
| 居住安静度 | 是否强调宜居、安静和生活稳定性 | 更多住宅、社区服务，减少高噪声功能 |
| 文创强度 | 是否强调创意产业和文化展示 | 更多创意办公、展览、工作室、文化教育 |
| 夜间活力 | 是否希望晚上和周末活跃 | 更多餐饮、剧场、娱乐、酒店 |
| 公共开放度 | 是否希望首层和街区开放 | 更多首层商业、展览、公共活动 |
| 混合使用度 | 是否希望功能复合 | 更多上下混合、边界混合 |
| 地标需求 | 是否需要标志性建筑或公共核心 | 更多总部、酒店、剧场、展览、会展 |

---

## 5.2 参数强度与权重修正

| 参数强度 | 功能权重修正 |
|---|---|
| 0—30 | 明显降低 |
| 31—45 | 小幅降低 |
| 46—60 | 基本不变 |
| 61—75 | 小幅提高 |
| 76—90 | 明显提高 |
| 91—100 | 强烈提高 |

注意：

> 用户愿景只调整候选功能优先级，不应突破分区定位和硬冲突规则。

---

# 6. 分区基础定位

四个分区有默认主导方向。用户愿景只能在此基础上修正，不能完全颠覆。

---

## 6.1 分区默认倾向

| 分区 | 商务 | 休闲消费 | 居住 | 文创 | 公共开放 | 夜间活力 |
|---|---:|---:|---:|---:|---:|---:|
| 中央商务区 | 90 | 50 | 20 | 30 | 60 | 40 |
| 休闲商业区 | 30 | 90 | 20 | 50 | 85 | 80 |
| 住宅区 | 15 | 30 | 90 | 20 | 40 | 20 |
| 文化创意产业园 | 40 | 55 | 35 | 90 | 75 | 50 |

解释：

- CBD 的商务强度最高；
- 休闲商业区的消费、开放和夜间活力最高；
- 住宅区的居住安静度最高；
- 文创园的文创强度最高，同时保持一定开放性和消费属性。

---

## 6.2 分区优先级修正

| 用户选择 | 分区权重修正 |
|---|---|
| 核心分区 | 明显提高 |
| 重要分区 | 小幅提高 |
| 普通分区 | 不变 |
| 弱化分区 | 小幅降低 |

修正逻辑：

- 核心分区中的主导功能更容易成为强推荐；
- 弱化分区不取消功能，只降低其扩张倾向；
- 四区均衡时，系统更强调功能互补和边界混合。

---

# 7. 标准功能库

AI 只能从标准功能库中选择功能。

不要自由生成“活力商业”“高级商业”“多元消费”“复合办公”等模糊名称。

---

## 7.1 工作生产类

| 标准功能 | 说明 | 主要适用分区 |
|---|---|---|
| 总部办公 | 高等级商务办公、企业总部、金融办公 | CBD |
| 标准办公 | 普通办公、专业服务办公 | CBD、文创园 |
| 创意办公 | 设计、传媒、艺术、策划类办公 | 文创园 |
| 设计工作室 | 小型创作、工作坊、创客空间 | 文创园 |

---

## 7.2 商业消费类

| 标准功能 | 说明 | 主要适用分区 |

# 9. 空间属性判断

建筑体块属性部分不需要在规则文档中规定具体接入方式，开发时根据目前体块属性自行判断如何接入。

只建议关注少量关键指标，用于前期轻量判断。

---

## 9.1 轻量空间指标

| 指标 | 用途 |
|---|---|
| 所属分区 | 判断基础功能范围 |
| 建筑高度或层数 | 判断适合办公、住宅、酒店还是低层商业 |
| 建筑底面面积 | 判断是否适合会展、剧场、展览、大型商业 |
| 临街或临公共空间程度 | 判断首层是否适合商业、餐饮、展览 |
| 与住宅核心的距离 | 判断高噪声功能是否需要回避 |
| 与交通节点或主路关系 | 判断商务、商业、酒店和会展适宜性 |
| 地标性或转角性 | 判断是否适合总部、酒店、剧场或公共核心 |

---

## 9.2 空间条件对功能的影响

| 空间条件 | 优先功能 | 应降低功能 |
|---|---|---|
| 高层体块 | 总部办公、标准办公、商务酒店、高端住宅、公寓 | 大型展览、剧场、纯低层商业 |
| 低层连续街区 | 生活方式零售、特色餐饮、文创零售、开放工作室 | 大型总部办公、高端住宅塔楼 |
| 大底面建筑 | 会展、剧场、展览、娱乐、大型商业 | 小型住宅、普通办公 |
| 强临街界面 | 零售、餐饮、展览、社区服务 | 封闭办公、纯住宅首层 |
| 靠近交通节点 | 办公、酒店、会展、商业 | 安静住宅、私密社区服务 |
| 靠近住宅核心 | 社区服务、社区零售、文化教育、住宅 | 娱乐、剧场、夜间餐饮、会展 |
| 地标位置 | 总部办公、酒店、剧场、展览、城市客厅 | 社区零售、普通配套 |

# 10. 楼层段规则

建筑不应只给整栋楼一个功能，而应按楼层段进行分配。

建议简化为：

1. 首层；
2. 裙房或低层；
3. 中层；
4. 高层；
5. 屋顶或特殊层。

|---|---:|---:|---:|---:|---:|

| 标准办公 | 1 | 3 | 5 | 4 | 1 |
| 创意办公 | 2 | 4 | 5 | 3 | 1 |

| 高端零售 | 5 | 5 | 2 | 0 | 1 |
| 生活方式零售 | 5 | 5 | 2 | 0 | 2 |
| 社区零售 | 5 | 3 | 0 | 0 | 0 |
| 商务餐饮 | 5 | 4 | 2 | 1 | 4 |
| 特色餐饮 | 5 | 4 | 1 | 0 | 4 |
| 休闲娱乐 | 3 | 5 | 3 | 0 | 2 |
| 商务会展 | 2 | 5 | 3 | 0 | 1 |
| 文化展览 | 5 | 5 | 3 | 0 | 2 |
| 剧场演艺 | 3 | 5 | 2 | 0 | 1 |
| 文化教育 | 3 | 4 | 4 | 1 | 1 |

---

## 10.2 首层判断

首层优先考虑城市界面。

判断顺序：

**临街/临公共空间程度 → 所属分区 → 公共开放度 → 与住宅核心关系 → 首层功能**

| 分区 | 高开放界面适合功能 | 低开放界面适合功能 |
|---|---|---|
| CBD | 高端零售、商务餐饮、酒店大堂 | 办公大堂、商务展示 |
| 休闲商业区 | 生活方式零售、特色餐饮、咖啡 | 精品酒店大堂、轻餐饮 |
| 住宅区 | 社区零售、社区服务 | 住宅大堂、邻里空间 |
| 文创园 | 文化展览、咖啡、开放工作室 | 创意办公入口、工作室 |

---

## 10.3 裙房或低层判断

裙房和低层优先考虑大平面、公共性和人流承载。

判断顺序：

**底面面积 → 是否适合大空间 → 所属分区 → 用户活力倾向 → 低层功能**

| 分区 | 裙房或低层适合功能 |
|---|---|
| CBD | 商务会展、高端零售、商务餐饮 |
| 休闲商业区 | 休闲娱乐、生活方式零售、剧场演艺 |
| 住宅区 | 社区服务、文化教育、少量社区商业 |
| 文创园 | 文化展览、设计工作室、发布空间、文化教育 |

---

## 10.4 中高层判断

中高层优先考虑稳定性、安静性和私密性。

判断顺序：

**所属分区 → 建筑高度 → 用户主导倾向 → 是否需要安静 → 中高层功能**

| 分区 | 中高层优先功能 |
|---|---|
| CBD | 总部办公、标准办公、商务酒店 |
| 休闲商业区 | 精品酒店、服务式公寓 |
| 住宅区 | 高端住宅、人才公寓 |
| 文创园 | 创意办公、人才公寓、精品酒店 |

---

## 10.5 屋顶或特殊层判断

屋顶和特殊层可作为体验增强空间，不宜影响主功能判断。

适合功能包括：

- 屋顶花园；
- 观景餐厅；
- 商务会所；
- 公共露台；
- 屋顶活动空间；
- 设备空间。

判断规则：

- CBD 屋顶可偏商务接待和观景消费；
- 休闲商业区屋顶可偏露台餐饮和公共活动；
- 住宅区屋顶应偏安静共享和社区花园；
- 文创园屋顶可偏展演、交流、活动和开放平台。

# 11. 综合评分逻辑

每个候选功能都可以得到一个 100 分制的综合适配判断。

不需要开发成复杂模型，但建议按以下权重理解：

| 评分项 | 建议权重 |
|---|---:|
| 分区适配 | 30% |
| 用户愿景适配 | 20% |
| 楼层段适配 | 20% |
| 体块空间适配 | 15% |
| 相邻协同 | 10% |
| 冲突惩罚 | -5% 至 -40% |

解释：

- 分区适配决定功能是否应该出现在该区；
- 用户愿景适配决定功能优先级；
- 楼层段适配决定功能是否适合该高度位置；
- 体块空间适配决定它是否适合这个建筑；
- 相邻协同用于增强合理组合；
- 冲突惩罚用于避免明显不合理结果。

---

## 11.1 综合分判断标准

| 综合分 | 处理方式 |
|---|---|
| 85—100 | 可作为强推荐主功能 |
| 70—84 | 可作为主功能 |
| 55—69 | 可作为次功能或补充功能 |
| 40—54 | 仅在特殊愿景下少量使用 |
| 0—39 | 不推荐 |
| 存在硬冲突 | 直接剔除，不参与排序 |

---

## 11.2 主功能与次功能选择

每个体块或楼层段最多输出：

- 1 个主功能；
- 1 个次功能；
- 1 条推荐理由；
- 必要时输出 1 条冲突提醒。

主功能选择规则：

1. 必须通过分区适配；
2. 必须通过楼层段适配；
3. 不能存在硬冲突；
4. 综合分最高；
5. 符合该分区主导方向。

次功能选择规则：

1. 综合分不低于 55；
2. 不能与主功能语义重复；
3. 不能与主功能冲突；
4. 最好与主功能形成协同。

---

# 12. 功能冲突规则

冲突规则优先级高于评分规则。

也就是说，某个功能即使综合分很高，只要触发硬冲突，就不能被采用。

---

## 12.1 硬冲突

以下情况应直接禁止：

| 情况 | 禁止结果 |
|---|---|
| 住宅区内部或住宅核心附近 | 禁止剧场演艺、休闲娱乐、商务会展作为主功能 |
| 住宅楼中高层 | 禁止商业零售、餐饮、娱乐作为主功能 |
| CBD 核心高层 | 禁止社区服务、社区零售作为主功能 |
| 休闲商业区核心首层 | 禁止纯封闭办公作为主功能 |
| 文创园核心开放界面 | 禁止纯封闭住宅作为首层主功能 |
| 安静内院界面 | 禁止夜间餐饮、娱乐、剧场作为主功能 |

---

## 12.2 软冲突

软冲突不直接禁止，但会降低评分，并提示规划师注意。

| 情况 | 处理方式 |
|---|---|
| 特色餐饮靠近住宅 | 降低评分，提示控制规模和营业时间 |
| 精品酒店靠近娱乐功能 | 可保留，提示注意噪声 |
| 文创园商业比例过高 | 提示避免变成普通商业街 |
| CBD 服务式公寓比例过高 | 提示可能削弱商务核心属性 |
| 住宅区社区商业过少 | 提示生活服务不足 |
| 休闲商业区办公比例过高 | 提示公共活力不足 |

---

## 12.3 语义冲突

以下组合不应同时作为主功能和次功能：

| 主功能 | 不应搭配的次功能 | 原因 |
|---|---|---|
| 高端零售 | 生活方式零售 | 同属零售，语义重复 |
| 商务餐饮 | 特色餐饮 | 同属餐饮，定位混乱 |
| 标准办公 | 总部办公 | 上下级概念混合 |
| 文化展览 | 文化教育 | 可相邻，但不宜作为同一楼层的主次功能混写 |
| 服务式公寓 | 精品酒店 | 居住与接待边界模糊 |
| 社区零售 | 社区服务 | 可相邻，但需要明确哪个是主导空间 |

---

# 13. 协同加分规则

协同关系可以提高两个功能相邻或上下组合的合理性。

| 功能组合 | 加分理由 |
|---|---|
| 总部办公 + 商务酒店 | 服务商务出行和总部接待 |
| 标准办公 + 商务餐饮 | 支撑工作日人流 |
| 商务会展 + 商务酒店 | 会议与住宿配套 |
| 高端零售 + 商务餐饮 | 形成 CBD 消费界面 |
| 生活方式零售 + 特色餐饮 | 形成休闲消费街区 |
| 休闲娱乐 + 特色餐饮 | 支撑夜间活力 |
| 文化展览 + 设计工作室 | 形成创意生产与展示闭环 |
| 创意办公 + 文化教育 | 形成培训、交流、孵化关系 |
| 高端住宅 + 社区服务 | 支撑日常生活 |
| 高端住宅 + 社区零售 | 提升生活便利性 |
| 人才公寓 + 创意办公 | 支撑文创园就业居住平衡 |
| 精品酒店 + 文化展览 | 服务游客和文化消费人群 |

# 14. 分区功能比例校正

单个体块评分完成后，还要检查整个分区的功能比例是否偏离过大。

这一步是为了避免所有建筑都被分配成同一种功能。

---

## 14.1 CBD 推荐比例

| 功能类型 | 建议比例 |
|---|---:|
| 总部办公 + 标准办公 | 50%—70% |
| 商务酒店 | 8%—18% |
| 商务会展 | 5%—15% |
| 高端零售 + 商务餐饮 | 10%—20% |
| 服务式公寓 | 0%—10% |

判断重点：

**办公必须是主体，酒店、会展和商业作为配套增强。**

---

## 14.2 休闲商业区推荐比例

| 功能类型 | 建议比例 |
|---|---:|
| 生活方式零售 | 20%—35% |
| 特色餐饮 | 15%—30% |
| 休闲娱乐 + 剧场演艺 | 15%—30% |
| 精品酒店 + 服务式公寓 | 5%—18% |
| 文化展览 + 文化教育 | 5%—15% |

判断重点：

**首层和低层必须有足够公共消费功能，不能被办公或住宅占满。**

---

## 14.3 住宅区推荐比例

| 功能类型 | 建议比例 |
|---|---:|
| 高端住宅 | 60%—80% |
| 人才公寓 | 5%—15% |
| 社区服务 | 5%—12% |
| 社区零售 | 3%—8% |
| 文化教育 | 3%—8% |
| 特色餐饮 | 0%—4%，且只宜在外围界面 |

判断重点：

**住宅是主体，商业和公共服务是配套，不能反客为主。**

---

## 14.4 文创园推荐比例

| 功能类型 | 建议比例 |
|---|---:|
| 创意办公 + 设计工作室 | 35%—60% |
| 文化展览 + 文化教育 | 15%—30% |
| 生活方式零售 + 特色餐饮 | 8%—20% |
| 人才公寓 | 5%—15% |
| 精品酒店 | 0%—8% |
| 剧场演艺 | 3%—10% |

判断重点：

**创意生产是主体，文化展示和消费是界面，商业不能盖过创意产业。**

---

# 15. 逐级下钻规则

这是避免冲突的关键。

AI 不应把所有条件平铺混算，而应按优先级逐级判断。

---

## 15.1 第一优先级：分区不能错

先判断建筑属于哪个分区。

例如：

- CBD 优先商务、办公、酒店、会展；
- 休闲商业区优先消费、餐饮、娱乐、剧场；
- 住宅区优先住宅、社区服务、社区零售、文化教育；
- 文创园优先创意办公、设计工作室、文化展览、文化教育。

即使用户强调夜间活力，也不能把住宅区内部大量变成娱乐或剧场。

---

## 15.2 第二优先级：硬冲突不能触发

在评分前，先排除明显不合理功能。

例如：

- 住宅核心附近排除剧场演艺和休闲娱乐；
- 高层住宅段排除零售和餐饮；
- CBD 高层排除社区服务；
- 休闲商业核心首层排除封闭办公。

---

## 15.3 第三优先级：楼层段要合理

不同楼层段有默认功能倾向：

| 楼层段 | 默认倾向 |
|---|---|
| 首层 | 公共界面、商业、餐饮、展览、社区服务 |
| 裙房或低层 | 商业、会展、剧场、展览、公共服务 |
| 中层 | 办公、住宅、公寓、酒店、教育 |
| 高层 | 总部办公、酒店、住宅、公寓 |
| 屋顶 | 花园、露台、会所、活动、设备 |

---

## 15.4 第四优先级：体块条件细化

在分区和楼层都合理的前提下，再根据体块条件细化。

| 条件 | 推导 |
|---|---|
| 高层 + CBD | 总部办公或商务酒店 |
| 大底面 + CBD | 商务会展 |
| 临街 + 休闲商业区 | 生活方式零售或特色餐饮 |
| 大空间 + 文创园 | 文化展览或剧场演艺 |
| 内部安静 + 住宅区 | 高端住宅或社区服务 |

---

## 15.5 第五优先级：用户愿景修正

用户愿景用于在合理候选中排序，而不是突破基本规则。

例如用户强调“夜间活力”：

| 分区 | 合理响应 |
|---|---|
| 休闲商业区 | 提高特色餐饮、剧场演艺、休闲娱乐 |
| 文创园 | 提高文化展览、剧场演艺、特色餐饮 |
| CBD | 提高商务餐饮、商务酒店、商务会展 |
| 住宅区 | 仅小幅提高外围低强度餐饮或社区活动，不引入高噪声娱乐 |

---

## 15.6 第六优先级：比例校正

完成单体分配后，检查整个分区比例。

例如：

- CBD 办公超过上限，后续高层可优先考虑商务酒店或服务式公寓；
- 休闲商业区餐饮过高，后续首层可增加零售、展览或娱乐；
- 住宅区商业过高，应回调为住宅、社区服务或文化教育；
- 文创园商业过高，应回调为创意办公、设计工作室、展览和教育。

---

# 16. 输出结果格式

AI 输出时不应只给功能名称，还应说明推荐依据。

每个体块或楼层段建议包含：

| 内容 | 要求 |
|---|---|
| 主功能 | 必须来自标准功能库 |
| 次功能 | 可选，不能语义重复 |
| 适配等级 | 强推荐 / 推荐 / 可选 / 不建议 |
| 主要依据 | 分区、楼层、体块条件、用户愿景 |
| 冲突状态 | 无冲突 / 有软冲突提醒 / 已规避硬冲突 |
| 可调整方向 | 提供用户继续修改的方向 |

---

## 16.1 示例输出

| 体块 | 分区 | 楼层段 | 主功能 | 次功能 | 适配等级 | 理由 |
|---|---|---|---|---|---|---|
| B01 | CBD | 首层 | 高端零售 | 商务餐饮 | 强推荐 | 位于商务区主街界面，公共开放度高，适合形成商务消费入口 |
| B01 | CBD | 中高层 | 总部办公 | 商务酒店 | 推荐 | 高层体块具有地标性，符合商务强度较高的愿景 |
| B02 | 休闲商业区 | 首层 | 生活方式零售 | 特色餐饮 | 强推荐 | 靠近公共空间，适合形成连续消费界面 |
| B03 | 住宅区 | 首层 | 社区服务 | 社区零售 | 推荐 | 位于住宅区，应服务日常生活并控制噪声 |
| B04 | 文创园 | 低层 | 文化展览 | 设计工作室 | 强推荐 | 适合形成创意生产与开放展示结合的界面 |

---

# 17. 用户后续调整方式

系统应支持用户继续用自然语言调整结果。

示例指令：

- 让住宅区更安静一点；
- 增加夜间活力；
- 减少 CBD 里的酒店比例；
- 让文创园更像艺术园区，而不是办公园区；
- 把沿主街的首层更多改成商业；
- 商业不要侵入住宅区内部；
- 增加面向年轻人的功能；
- 让整体更高端、更商务；
- 把文创园和休闲商业区联系得更紧密。

AI 接收这些反馈后，不应重新推翻全部结果，而应局部调整相关分区、体块或楼层段。

---

# 18. 建议前端交互方式

前端可以采用“最少必填 + 可选补充”的方式。

---

## 18.1 最小输入模式

只要求用户填写：

> 一句话愿景

其余字段均可默认待定，由 AI 自动补全。

适合快速生成方案。

---

## 18.2 标准输入模式

用户填写：

1. 一句话愿景；
2. 服务人群画像；
3. 核心分区；
4. 活力时段；
5. 开放程度；
6. 是否需要地标或公共核心。

适合希望更精确控制方案方向的用户。

---

## 18.3 交互原则

每一步都应支持：

- 单选；
- 多选；
- 待定；
- 其它输入；
- 后续修改。

AI 输出时应明确区分：

| 类型 | 表达方式 |
|---|---|
| 用户明确指定 | 根据你的选择…… |
| 用户自定义输入 | 根据你补充的描述…… |
| AI 自动推断 | 由于该项待定，系统根据愿景推断…… |
| 默认规则 | 在未指定倾向时，系统采用分区默认逻辑…… |

这样可以保证用户即使只输入一句愿景，也能得到完整功能排布；如果用户想更深入控制，也可以逐步补充信息。

---

# 19. 核心总结

这套规则的核心是：

> 分区决定能放什么，用户愿景决定更偏向什么，楼层段决定放在建筑哪里，体块条件决定哪栋更适合，冲突规则决定哪些不能放，比例校正决定整体是否均衡。

最终判断链条为：

**愿景输入 → 参数转译 → 分区定位 → 标准功能库 → 空间属性 → 楼层段 → 适配评分 → 功能分配 → 冲突与比例校验 → 可解释输出**

这套逻辑应保持轻量化，用于城市设计前期辅助判断，而不是替代规划师做最终业态策划。
