# V / T / S 数据处理方法说明

本文档整理 **活力压力（V）**、**时间压力（T）**、**空间承载力（S）** 的指标逻辑、公式框架、可用数据、计算与制图输出，以及与设计策略的对应关系。三张核心表的数学结构如下述；**状态判断**可采用 **均值 ± 标准差（μ ± σ）** 作为分位阈值，便于在 **QGIS** 中直接对 **z-score 栅格** 做分级与制图。

---

## 1. 总览：三张表的公式逻辑

### 1.1 V — 活力压力（Vitality Pressure）

核心是 **三分量加权合成**，并借鉴城市活力研究中的 **核密度估计（KDE）**：

- **\(V^{com}\)**：采用 **评分加权的 POI 核密度**（可参考 Yue et al., 2017, *Urban Studies* 一类做法）。
- **\(V^{dwell}\)**：引入 **指数衰减**，刻画到 **交通节点** 的距离衰减。
- **\(V^{flow}\)**：结合 **人口密度相对水平** 与 **客流（或对数变换后的流量项）**，表达 **人流潜力**。

状态判断建议使用 **\(\mu_V \pm \sigma_V\)**（或等价的分位数 / z-score 阈值），与 **空间供给 \(S_i\)**、**转化效率**、**人口 vs 公服**、**文保敏感度** 等联合解读（见第 4 节）。

### 1.2 T — 时间压力（Temporal Pressure）

- 引入 **Shannon 时间熵 \(H_{T,i}\)**，刻画某单元在 **全天各时段流量分布的均匀程度**：熵 **高** 表示 **全时段都有人**；熵 **低** 表示流量 **集中在峰值**。
- 配合各时段流量的 **z-score 偏差 \(\Delta TP_i(t)\)**，识别 **分时段超载强度**。
- 该组合可基于 **客流时序 CSV**，在 **Python** 中批量计算后输出分级图或时间切片图。

### 1.3 S — 空间承载力（Spatial Capacity）

- 引入 **Space Syntax 全局整合度 \(\Omega_i\)** 作为 **连通潜力** 的量化项，相较单纯 **路网密度** 更具空间句法依据。
- **结构可行性系数 \(C_{struct,i}\)**：将 **跨度、层高、荷载** 等工程变量折算为综合系数。
- **风险惩罚项 \(P_{risk,i}\)**：可叠加 **文保范围、地质与坡度** 等约束。

## 2. V：活力压力（Vitality Pressure）

### 2.1 它回答什么

- 哪里有 **潜在活力**？哪里主要是 **被动通行**？
- 哪里具备 **消费** 与 **停留** 潜力？

### 2.2 综合指标形式

对单元 \(i\)，活力压力指数可写为三分量的加权合成：

\[
V_i = \alpha \cdot V^{flow}_i + \beta \cdot V^{com}_i + \gamma \cdot V^{dwell}_i
\]

#### （1）人流潜力项 \(V^{flow}_i\)（Kernel-weighted transit–population potential）

\[
V^{flow}_i = \frac{\rho_i}{\bar{\rho}} \cdot \left(1 + \ln\left(1 + \frac{Flow_i}{\overline{Flow}}\right)\right)
\]

其中 \(\rho_i\) 为人口密度（或栅格人口），\(\bar{\rho}\) 为参照均值；\(Flow_i\) 为与站点/通道相关的客流或流量代理，\(\overline{Flow}\) 为参照。

#### （2）消费活力项 \(V^{com}_i\)（Review-weighted POI kernel density）

\[
V^{com}_i = \frac{1}{A_i} \sum_j POI_j \cdot Score_j \cdot K_h(d_{ij})
\]

\(K_h(\cdot)\) 为带宽 \(h\) 的 **高斯核**；\(d_{ij}\) 为 POI \(j\) 到单元 \(i\) 代表点（或核中心）的距离；\(Score_j\) 可为点评评分、权重等；\(A_i\) 为单元面积，用于密度化。

#### （3）停留需求项 \(V^{dwell}_i\)（Decay-adjusted public facility density）

\[
V^{dwell}_i = \frac{F^{pub}_i}{A_i} \cdot \exp\left(-\lambda \cdot d^{transit}_i\right)
\]

\(F^{pub}_i\) 为公共设施规模（或公服 POI 核密度积分）；\(d^{transit}_i\) 为到轨道交通节点等的距离；\(\lambda\) 控制衰减速度。

**符号备忘：** \(\mu_V,\sigma_V\) 为 \(V\) 的全局均值与标准差；\(K_h(d)\) 为高斯核；\(\theta_{conv}\) 为 **商业转化** 判别阈值；\(H^{her}_i\) 为 **文保敏感度** 等指标。

### 2.3 可用数据

- POI  
- 美团 / 大众点评  
- WorldPop（或普查/格网人口）  
- 交通站点与客流  
- 房价或租金（可选，作混合度/支付意愿代理）  
- 客流时序（与 \(V^{flow}\)、转化分析衔接）  
- 公共服务设施点  

### 2.4 计算思路（与三分量对应）

活力压力可理解为：

\[
V \approx \text{人流潜力} + \text{消费活力} + \text{停留需求}
\]

可纳入的构造性变量包括：

- 人口密度（WorldPop / 普查格网）  
- 站点客流（或代理）  
- 商业 POI 密度与核密度  
- 餐饮 **数量 + 评分** 加权  
- 公共设施密度与衰减距离  
- 到交通节点距离  
- 周边 **居住—办公** 混合程度（用地、POI 类型或房价梯度等）  

### 2.5 建议输出图

- 潜在活力热力图（综合或 \(V^{flow}\)）  
- 消费活力图（\(V^{com}\)）  
- 人流压力图  
- 停留空间不足 / 公服缺口示意  
- 活力转化断点图（结合 \(C_i/V_i\) 或商业渗透）  

### 2.6 状态判断与设计含义（V 侧重）

| 状态判断（阈值条件示意） | 设计含义 |
| :--- | :--- |
| \(V_i > \mu_V + \sigma_V\) 且 \(S_i < \mu_S\) | **活力外溢而空间供给不足**：需要广场、廊道、复合界面 |
| \(V_i > \mu_V\) 且 \(C_i / V_i < \theta_{conv}\) | **活力转化效率偏低**：需要站城商业转换空间 |
| \(\rho_{pop,i} > \bar{\rho}\) 且 \(F^{pub}_i / A_i < \bar{F}^{pub}\) | **人口高但公服不足**：需要社区客厅与共享设施 |
| \(V_i > \mu_V\) 且 \(H^{her}_i > \bar{H}^{her}\) | **活力与文保敏感重叠**：轻介入、慢更新、低强度激活 |

## 3. T：时间压力（Temporal Pressure）

### 3.1 它回答什么

同一空间在 **早高峰、平峰、夜间、周末** 是否呈现 **不同状态**？分时段的 **压力** 与 **机会** 各在哪里？

### 3.2 指标形式

**时段压力比：**

\[
TP_i(t) = \frac{Flow_i(t)}{\overline{Flow_i}}
\]

（可按研究定义 \(\overline{Flow_i}\) 为单元日均或参照量。）

**时段占比（用于 Shannon 熵）：**

\[
p_t(i) = \frac{Flow_i(t)}{\sum_t Flow_i(t)}
\]

**标准化 Shannon 时间熵：**

\[
H_{T,i} = -\frac{\sum_t p_t(i) \ln p_t(i)}{\ln T} \in [0,1]
\]

\(T\) 为时段划分数；\(H_{T,i}\) 越高，全天分布越 **均匀**。

**流量 z-score 偏差：**

\[
\Delta TP_i(t) = \frac{Flow_i(t) - \mu_{Flow,i}}{\sigma_{Flow,i}}
\]

### 3.3 时间切片建议

| 切片 | 含义（可据数据调整时段边界） |
| :--- | :--- |
| T1 | 工作日早高峰 |
| T2 | 工作日平峰 |
| T3 | 工作日晚高峰 |
| T4 | 夜间 |
| T5 | 周末 / 节假日 |

### 3.4 可用数据

- 客流时序（AFC、闸机、调研、手机信令等）  
- 交通运行数据  
- POI **营业时间**（粗代理，见本项目制图说明）  
- 美团 / 大众点评活跃时段（若可获取）  
- 公交 / 地铁运营时间  
- 手机信令（若合规可得）  
- 公开交通年报与文献参数  

### 3.5 建议输出图

- 早高峰流动压力图  
- 夜间活力衰减图  
- 周末活动潜力图  
- 分时段界面需求图  
- 动态开放策略图（与熵、平峰机会联合表达）  

### 3.6 状态判断与设计含义（T 侧重）

| 状态 / 时间切片条件（示意） | 设计含义 |
| :--- | :--- |
| **T1 早高峰**：\(\Delta TP_i(7\text{–}9h) > \mu + 1.5\sigma\) | 通廊、换乘、疏散优先 |
| **T2 平峰**：\(H_{T,i}\) 高且平峰 \(\Delta TP\) 相对低 | 可引入商业、展览、休憩 |
| **T4 夜间**：\(Act_i(22\text{–}6h) / \overline{Act_i} < 0.3\)（活力衰减显著） | 文化、照明、安全界面 |
| **T5 周末**：\(\sigma_{wknd,i}/\sigma_{wkdy,i} > \lambda_T\) | 活动场地与弹性空间 |

**符号备忘：** \(H_{T,i}\) 为标准化 Shannon 时间熵；\(\Delta TP\) 为 z-score 流量偏差；\(\lambda_T\) 为周末弹性阈值；\(Act_i(t)\) 为时段 \(t\) 活力强度。

### 3.7 设计意义（T，汇总表）

| 状态判断 | 设计含义 |
| :--- | :--- |
| 早高峰压力高 | 通廊、换乘、疏散优先 |
| 平峰压力低 | 可引入商业、展览、休憩 |
| 夜间活力低 | 文化、照明、安全界面 |
| 周末潜力高 | 活动场地与弹性空间 |

## 4. S：空间承载力（Spatial Capacity）

### 4.1 它回答什么

- 哪里 **有能力承载** 新增体量？  
- 哪里适合 **掏空、架空、加盖、退让**？  

### 4.2 综合指标形式

\[
S_i = w_1 \cdot \Delta FAR_i + w_2 \cdot C_{struct,i} + w_3 \cdot \Omega_i - w_4 \cdot P_{risk,i}
\]

- **\(\Delta FAR_i\)**：剩余开发强度，\(\Delta FAR_i = FAR_{max,i} - FAR_{cur,i}\)。  
- **\(C_{struct,i}\)**：结构可行性系数，可为 \(f(span_i, h_i, load_i)\) 等（跨度 × 层高 × 荷载等）。  
- **\(\Omega_i\)**：Space Syntax **全局整合度** 在单元上的面积加权平均（连通潜力）。  
- **\(P_{risk,i}\)**：文保、陡坡、地质等 **风险惩罚**。  

### 4.3 可用数据

- 建筑轮廓、高度  
- Rhino 建筑体块  
- DEM  
- 上海地块 / 权属与规划图则（FAR 上限）  
- 城市建成区与用地  
- CAD、卫星影像  
- 开源土地利用  

### 4.4 计算方法（与指标衔接）

- 建筑密度、容积率估算、建筑高度  
- 空地率、地块尺度、现状用地强度  
- 铁路上盖可行性分区、结构跨度条件  
- 既有建筑保留与拆改可能性  
- Space Syntax 整合度（DepthMapX / sDNA / 等工具链）  

### 4.5 建议输出图

- 现状开发强度图  
- 低效用地识别图  
- 可加盖潜力图  
- 可掏空空间图  
- 三维体素承载模型（可选）  

### 4.6 状态判断与设计含义（S 侧重，及与 V、T 联动）

| 状态判断（容量条件示意） | 设计含义 |
| :--- | :--- |
| \(\Delta FAR_i > \overline{\Delta FAR}\) 且 \(\Omega_i > \overline{\Omega}\) | 高剩余强度 × 高连通潜力：适合 **核心复合体量** |
| \(\Delta FAR_i > \overline{\Delta FAR}\) 且 \(V_i < \overline{V}\) | 承载力足但活力不足：适合 **导入新功能** |
| \(\Delta FAR_i < \overline{\Delta FAR}\) 且 \(TP_i > \overline{TP}\) | 容量紧、交通/客流压力大：适合 **轻量化连廊或开放空间** |
| \(span_i > 24\text{m}\) 且 \(C_{struct,i} < \overline{C_{struct}}\) | 大跨度铁路上盖等：**结构系统优先介入** |

### 4.7 设计意义（S，汇总表）

| 状态判断 | 设计含义 |
| :--- | :--- |
| 高承载能力 + 高连通潜力 | 适合设置核心复合体量 |
| 高承载能力 + 低活力 | 适合导入新功能 |
| 低承载能力 + 高交通压力 | 适合轻量化连廊或开放空间 |
| 大跨度铁路上方 | 需要结构系统优先介入 |

## 5. 综合设计意义（V + T + S）

将 **活力压力、时间压力、空间承载** 与 **转化、人口—设施、文保** 等联合判断时，可采用如下 **状态—策略** 对应（可与第 2–4 节表格合并使用）：

| 状态判断 | 设计含义 |
| :--- | :--- |
| 高活力压力 + 低空间承载 | 需要广场、廊道、复合界面 |
| 高客流 + 低消费转化 | 需要站城商业转换空间 |
| 高人口 + 低公共空间 | 需要社区客厅和共享设施 |
| 高活力 + 高文保敏感 | 需要轻介入、慢更新、低强度激活 |

## 6. 与当前项目制图脚本的关系（简要）

仓库内 `scripts/generate_vts_maps.py` 基于 **裁切后的 `site_clipped`** 数据，输出 **CartoDB Positron** 底图上的 **V/T/S 示意图层**（如 POI KDE、Dianping、公服 POI、建筑高度、WorldPop 等）。其指标为 **数据可得情况下的代理**，完整实现上表中的 **\(V^{flow}\)、\(H_{T,i}\)、\(\Delta FAR\)、\(\Omega\)** 等需补充 **客流时序、规划 FAR、Space Syntax 分析** 等数据与工序；本文档作为 **方法定义与扩展路线** 使用。
